# Miro-доска «Т-Инвестиции»

Доска: https://miro.com/app/board/uXjVEe4xbpg=/. Её параллельно правит вся команда, поэтому перед любой правкой фрейма заново прочитай его актуальное состояние.

## Порядок работы
1. Загрузить схемы инструментов через ToolSearch: `canvas_get_canvas_composer_skill`, `canvas_search`, `canvas_read_as_svg`, `canvas_update_from_svg`, `canvas_create_from_svg`.
2. `canvas_get_canvas_composer_skill` — сначала без `step`, затем с `edit` или `design`.
3. `canvas_search` (overview / areas / matches) — найти фреймы. Список ниже может устареть.
4. `canvas_read_as_svg` по `widget_ids` фрейма.
5. `canvas_update_from_svg` (правка) или `canvas_create_from_svg` (новое).

Формат фрейма: `<g data-miro-id=… transform="translate(x,y)" data-frame="">` + `<rect data-type="frame">`; координаты детей — относительно фрейма.

## Правила
- Чужие фреймы не переписывать: новое — в отдельный фрейм рядом.
- Удаление (`data-deleted="true"`) необратимо — только с явного подтверждения пользователя.
- Форма стикера (квадратный или широкий) фиксируется при создании, ресайз её не меняет. Некоторые стикеры Miro отказывается ресайзить («Miro did not confirm»), но двигать их можно.
- Пользователь не видит изменений — попросить обновить вкладку (F5).
- Цвет статуса вопросов во фрейме «ТЗ»: белый, серый, красный — нет ответа; `light_yellow` — частично; `dark_green` — полностью.

## Фреймы
Список с id — в `frames.md`; читать, когда нужен конкретный фрейм.

ADR команда оформляет канвасами на доске; текстовые копии лежат в `adr/` репозитория `documentation`. Изменился ADR на доске — обнови копию.
