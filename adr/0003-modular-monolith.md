# ADR-0003: Модульный монолит

- Ответственные: Максим Токарев
- Статус: выбрано (поле статуса на доске не заполнено)
- Дата: 28.10.2026
- Связано: `architecture.md`
- Оригинал: Miro, фрейм `3458764688661358362`

## Проблема
Четыре студента делают продукт за один учебный год.

## Итоговое решение
Java-бэкенд — модульный монолит на Spring Boot + Spring Modulith.

## Альтернативы
- Обычный монолит — отклонено.
- Микросервисы — отклонено.

## Допущения
Независимые релизы Java-модулей пока не нужны; модули делят ресурсы и сбои одного процесса.
