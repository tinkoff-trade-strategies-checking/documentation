# ADR-0005: Выходной веб-сервер и reverse proxy

- Ответственные: Максим Токарев
- Статус: выбрано (поле статуса на доске не заполнено)
- Дата: 28.10.2026
- Связано: НФТ-6
- Оригинал: Miro, фрейм `3458764688707977655`

## Итоговое решение
Caddy вместо Nginx: HTTPS, раздача SPA, reverse proxy `/api`. Выбор основан на простоте сопровождения, а не на предположении о большей скорости.

## Альтернативы
- Nginx — отклонено.
- Только Spring Boot, SPA упакована в JAR — отклонено: Angular собирается отдельно, фронт и бэк обновляются раздельно.
