# ADR-0002: Обмен командами и событиями

- Ответственные: Максим Токарев
- Статус: выбрано (поле статуса на доске не заполнено)

## Итоговое решение
Команды — REST, события сервера — SSE.

## Альтернативы
- REST + опрос — отклонено.
- REST + WebSocket — отклонено.

## Допущения
- Клиенту передаются обновления для UI, а не каждый тик.
- Расчёт продолжается без открытой вкладки; ручная сессия при этом ставится на паузу.
