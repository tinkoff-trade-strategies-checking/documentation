# ADR

Architecture Decision Records — архитектурные решения с причинами. Команда оформляет ADR канвасами на Miro-доске; здесь — их текстовые копии для поиска и ссылок из кода. При расхождении приоритет у доски, копию нужно обновить.

Файл `NNNN-кратко.md`, номер растёт по порядку. Принятый ADR не переписывают: если решение меняется, пишут новый ADR, а в старом ставят статус «ЗАМЕНЕНО ADR-NNNN». Шаблон — `0000-template.md`.
