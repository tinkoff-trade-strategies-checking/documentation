# ADR-0013: Чтение ClickHouse из C++ по HTTP-интерфейсу

- Ответственные: агент `architect` (по реализации `core` PR #6)
- Статус: Предложен (предложено агентом, ждёт подтверждения команды)
- Дата: 03.11.2026
- Связано: ФТ-3, ФТ-5, INV-1, INV-5, INV-6, INV-10, ADR-0004; план реализации, задачи 34 и 62
- Оригинал: на Miro нет

## Проблема
Simulation Worker читает свечи и справочник бумаг из ClickHouse (ADR-0004). Нужно выбрать протокол и библиотеку клиента в C++. `core/AGENTS.md` требует ADR на библиотеку и формат чтения ClickHouse.

## Факторы
- Сборка `core` берёт зависимости из apt (Docker, CI на ubuntu-24.04).
- Цены без `double` (INV-6).
- Только чтение и только готовые снапшоты (INV-5, INV-10).
- Объём одного запроса — серия баров одной бумаги, не поток.

## Альтернативы
- **HTTP-интерфейс ClickHouse через libcurl, формат `TabSeparated`** — выбрано: libcurl есть в apt (`libcurl4-openssl-dev`), протокол простой; числа приходят текстом и разбираются `Decimal::parse` без `double`.
- `clickhouse-cpp` (нативный протокол) — отклонено: нет в apt, сборка тяжелее (своя зависимость в Docker и CI).

## Допущения
- Серия баров читается одним запросом целиком; если понадобится потоковое чтение больших серий — пересмотреть.
- Интеграционный тест с настоящим ClickHouse в CI пока не входит (нужен импортёр с фикстурой); запускается вручную по рецепту `core/AGENTS.md`.

## Итоговое решение
`ClickHouseBarSource` (`core/src/worker/clickhouse/`) ходит в ClickHouse по HTTP через libcurl:
- каждый запрос с `readonly=1`, параметризованный (`{name:Type}` и `param_*`), идентификаторы бумаг в текст SQL не подставляются;
- ответ — `TabSeparated`, цены — `Decimal::parse` из текста;
- читаются только снапшоты из представления `snapshots_ready`; нет снапшота — `SnapshotNotFound`;
- свечи — из `candles`, если для бумаги и интервала они есть, иначе из `candles_from_trades`.
