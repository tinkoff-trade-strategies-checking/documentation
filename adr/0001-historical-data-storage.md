# ADR-0001: Хранение исторических данных

- Ответственные: Владислав Гаев
- Статус: ОБСУЖДАЕТСЯ (на доске не заполнен, решение оспаривается)
- Дата: 27.10.2026
- Связано: ФТ-3, ФТ-4, ADR-0004
- Оригинал: Miro, фрейм `3458764688493655357`

## Итоговое решение
Хранить исторические данные на собственной стороне, предварительно загружая их из API Мосбиржи или сторонних агрегаторов.

## Открытые вопросы (из обсуждения на доске)
- Что храним: все сделки или свечи (1h / 1m / 1s), какую глубину истории, какие бумаги. Звучало «10 лет для MVP хватит» и сомнение «вывезем только минутные свечи».
- Объём: оценки расходятся от ~20 ГБ (все акции) до 300+ ГБ (500 бумаг за 10 лет); на сервере свободно 196 ГБ. Проверка: история сделок за месяц загружена в локальный ClickHouse, результат — скриншот на доске.
- Доступ к API MOEX для выкачки может быть ограничен; рассматривается ключ к T-Bank API.
