# ADR-0011: TS-клиент API генерирует ng-openapi-gen

- Ответственные: агент `architect`
- Статус: Предложен (предложено агентом, ждёт подтверждения команды)
- Дата: 03.11.2026
- Связано: НФТ-6, ADR-0007, ADR-0009; план реализации, задача 6
- Оригинал: на Miro нет

## Проблема
По ADR-0007 фронтенд хранит копию `backend/api/openapi.yaml` и генерирует из неё TS-клиент при сборке. Нужно выбрать генератор. `frontend/AGENTS.md` требует ADR на способ генерации клиента.

## Факторы
- Сборка и CI фронтенда без лишних сред выполнения.
- Клиент в стиле Angular: сервисы с `HttpClient`, standalone-приложение.
- Поддержка OpenAPI 3.1 (контракт написан на 3.1).

## Альтернативы
- **ng-openapi-gen** — выбрано: пакет npm на Node, отдельная Java не нужна; генерирует Angular-сервисы и модели.
- `openapi-generator-cli` (генератор `typescript-angular`) — отклонено: нужна Java в CI и у каждого разработчика фронтенда.
- Писать клиент руками — отклонено: расходится с контрактом незаметно.

## Допущения
- События SSE клиент не генерирует: из схем `components/schemas` получаются только типы событий, сам поток читает сервис `EventSource` (`src/app/core/sse/`).
- Если генератор не справится с конструкцией OpenAPI 3.1 из контракта, правится контракт или выбирается другой генератор новым ADR.

## Итоговое решение
`ng-openapi-gen` генерирует клиент из `frontend/api/openapi.yaml` в `src/app/core/api/generated/` перед сборкой, тестами и `npm start`; сгенерированный код не коммитится.
