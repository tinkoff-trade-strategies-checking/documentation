# ADR-0006: Четыре репозитория и симулятор на C++

- Статус: Предложен (Денис Муруев; репозитории созданы 30.10.2026)
- Дата: 2026-10-30
- Связано: НФТ-2, НФТ-6, INV-4

## Контекст
Продукт состоит из веб-клиента, бэкенда с бизнес-логикой и симулятора рынка, через который проходит рыночный цикл. Стек и границы — в `architecture.md`.

## Решение
Четыре репозитория в организации `tinkoff-trade-strategies-checking`:
- `frontend` — Angular + Taiga UI;
- `backend` — Java, Spring Boot + Spring Modulith;
- `core` — C++20 ядро симуляции рынка (Simulation Core) и gRPC-сервер (Simulation Worker);
- `documentation` — общие знания: требования, инварианты, архитектура, ADR, статус.

Java и C++ общаются по gRPC; рыночный цикл и свечи не проходят через Java.

## Последствия
- Общие контракты (`.proto`, OpenAPI) нужно где-то хранить и версионировать — вопрос открыт (`status.md`).
- Изменение, затрагивающее несколько репозиториев, требует согласованных PR.
- Правила, общие для всех репозиториев, живут в `documentation`, а не копируются в каждый.
